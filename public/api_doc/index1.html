Mukafa API

API for managing partners, staff, members, transactions, and reward cards.

Partner: A partner represents a business or organization that can register and manage members in the Mukafa system. To begin, a partner must first register with Mukafa by submitting their details. Upon successful registration and approval from the Mukafa team, the partner will gain API access. This process includes whitelisting the partner's IP address to ensure secure communication with the Mukafa system. Once approved, the partner will receive login credentials that allow authentication using an email and password to obtain an API token. This token must be included in the Authorization header as a Bearer token in subsequent requests.

Card: Cards represent a tiered rewards system associated with a partner. These cards define the rules and benefits, such as how many Mukafa points a user earns based on specific actions, like spending money on the partner's platform. For example, a user may be assigned a Tier 1 card, where for every 100 units spent, they earn 100 Mukafa points. Depending on the card tier, the reward may vary, with higher tiers offering more points or additional benefits (e.g., Tier 2 may offer 150 points for the same amount spent).Additionally, based on the member's activity and performance, they may be promoted to a higher tier. For instance, if a user spends more or meets certain performance metrics defined by the partner, they can move from Tier 1 to Tier 2, which provides greater rewards, such as earning more Mukafa points per transaction.

Member: A member is an individual registered under a partner who participates in the Mukafa program. Members receive a Mukafa number, can track their points balance, and participate in the rewards system. Each member has unique information, such as their phone number, birthday, and account balance.
