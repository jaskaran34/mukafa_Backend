Mukafa API Error Information

1. Member/Customer Register API

Attribute Details
Endpoint POST {{baseurl}}/member/register
Request Body (JSON)
  • name (string, required): Customer's full name.
  • email (string, optional, unique): Customer's email (must be unique if provided).
  • phone_prefix (string, required): Phone number prefix (e.g., "+1").
  • phone (string, required): Phone number (combined with phone_prefix, must be unique).
  • birthday (string, required): Date of birth (YYYY-MM-DD).
  • partner_id (string, required): Partner's unique identifier.
Responses
  • 201 Created: Customer successfully created.

  • 422 Unprocessable Entity: Validation error (e.g., non-unique phone, missing fields, or invalid data). 
    {
  "errors": {
    "name required",
    "email already exist"
    "phone": "Phone number already exists",
    "birthday": "Birthday is required"
  }
}
  • 404 Not Found: Partner not found. 
    {
  "message": "Partner not found"
}

2. Add Purchase API

Attribute Details
Endpoint POST {{baseurl}}/partner/cards/{{carduid}}/{{member_id}}/transactions/purchases
Request Body (JSON)
  • purchase_amount (numeric, required,greater than 0): The amount of the purchase.
  • order_id (string, required, unique): A unique identifier for the order.
  • integration_id (string, required): The integration ID (must exist in the system).
Responses
  • 201 Created: Purchase successfully added. 
    {
  "message": "Purchase added successfully"
}
  • 422 Unprocessable Entity: Validation error (e.g., missing fields, invalid data, or non-unique order_id). 
    {
  "errors": {
    "purchase_amount": "Purchase amount is required",
    "order_id": "Order ID must be unique",
    "integration_id": "Integration ID does not exist",
    "memberuid or carduid not found".
  }
}

3. Cancel Transaction API

Attribute Details
Endpoint POST {{baseurl}}/transactions/{{tran_id}}/cancel
Request Body (JSON)
  • cancel_type (string, required): Type of cancellation (F for full, P for partial).
  • points (integer, optional): Points to cancel (required for partial cancellation).
Responses
  • 200 OK: Transaction successfully cancelled. 
    {
  "message": "Transaction cancelled successfully"
}
  • 422 Unprocessable Entity: Validation errors. 
    {
  "message": "Validation error",
  "errors": {
    "Transaction Already Cancelled": "Transaction Already Cancelled.",
    "Transaction Already Partially Cancelled": "Transaction Already Partially Cancelled.",
    "Cancelled Amount greater than transaction balance": "Cancelled Amount greater than transaction balance.",
    "Points to be cancelled more than original transaction": "Points to be cancelled more than original transaction.",
    "Invalid Data": "Invalid Data.",
    "Invalid cancel_type": "Invalid cancel_type."
  }
}
  • 404 Not Found: Transaction not found. 
    {
  "message": "Transaction not found."
}

4. Find Member and gettransactions API

Attribute Details
Endpoint GET findmember: {{baseurl}}/partner/member/{{member_id}}

GET gettransactions: {{baseurl}}/partner/transaction/member/{{member_id}}
Request Body None
Responses
  • 200 OK
  • 404 Not Found: Member not found. 
    {
  "message": "Member not found"
}

5. Redeem Points API

Attribute Details
Endpoint POST {{baseurl}}/partner/cards/{{carduid}}/{{member_id}}/transactions/points/redeem
Request Body (JSON)
  • points (numeric, required, gt>0): Points to redeem.
  • order_id (string, required, unique): A unique identifier for the redemption.
  • Integration id (string,required)
Responses
  • 201 OK: Points successfully redeemed. 
    {
  "message": "Points redeemed successfully"
}
  • 422 Unprocessable Entity: Validation errors. 
    {
  "errors": {
    "points": "Points are required",
    "order_id": "Order ID must be unique",
    "insufficient_points": "Insufficient points to redeem"
    "memberuid or carduid not found."
  }
}
